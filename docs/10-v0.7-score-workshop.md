# v0.7 ABC Score Workshop — 실험 기능

## 지원 범위와 기술 근거

현재 설치된 audio.cpp v0.8.1의 model_specs/yue2.json과 CLI 도움말, 해당 태그의 공식 엔진 문서를 확인했습니다. 외부 ABC는 `cot=melody/full` + `abc_file`로 입력하며, 모델이 생성한 악보는 `--out-dir` 지정 시 `score.abc`로 저장됩니다. 엔진 교체나 추가 모델 다운로드 없이 구현했습니다.

- [audio.cpp v0.8.1 YuE2 문서](https://github.com/0xShug0/audio.cpp/blob/v0.8.1/docs/models/yue2.md)
- [YuE 공식 악보 편집 안내](https://github.com/multimodal-art-projection/YuE/blob/main/docs/editing.md)

이번 버전은 **ABC 텍스트 편집 → 새 음원 생성**입니다. 오선보/피아노롤, 악보 미리 듣기, 오디오 자동 채보, 자동 작곡 에이전트는 포함하지 않습니다. 악보는 모델의 계획이며 실제 음원에서 추출한 확정 악보가 아닙니다. 템포·음정·화성의 실현 정도와 기존 음색 보존은 청취 확인이 필요합니다. 수정은 새 전체 녹음을 생성하며 기존 WAV를 부분 수정하지 않습니다.

## 사용법

1. 새 악보를 얻으려면 세부 생성 설정에서 **멜로디 계획** 또는 **멜로디 + 화성 계획**으로 곡을 생성합니다. 바로 생성(cot=off)은 악보를 만들지 않습니다.
2. 라이브러리에서 결과 선택 → **ABC 악보 보기 → 악보 불러오기**로 텍스트를 확인하거나 **ABC 다운로드**로 저장합니다.
3. **악보 수정 버전 만들기**를 누르면 확인 후 원본 가사·스타일·설정과 보관된 악보를 초안으로 가져옵니다. Score Revision 부모 관계도 함께 설정합니다.
4. Compose의 **ABC 악보 편집**에서 텍스트를 수정합니다. **악보 헤더 확인**은 T/M/L/Q/K 헤더와 글자 수만 검사합니다. 완전한 ABC 파서나 음표/마디 유효성 검사가 아닙니다.
5. **이 ABC 악보를 생성에 사용**을 선택하고 멜로디/화성 계획 모드로 음악을 만듭니다. cot=off와 ABC 동시 사용은 UI와 서버 모두 거부합니다.
6. 새 결과는 원본과 별개로 저장됩니다. Song Versions에서 두 버전의 악보·입력 차이를 비교하고 번갈아 들어볼 수 있습니다.

직접 ABC를 붙여넣거나 UTF-8 .abc/.txt 파일을 가져올 수도 있습니다. 파일 가져오기는 현재 텍스트 교체 확인을 받으며 자동으로 생성하지 않습니다. 체크를 해제하면 텍스트는 초안에 남지만 엔진에 보내지 않습니다. 기존 “이 곡에서 새 버전”은 저장된 생성 입력을 가져오는 기능이므로 모델이 생성한 계획을 편집하려면 전용 **악보 수정 버전 만들기**를 사용하세요.

기존 곡에 악보가 없으면 그 사실을 표시합니다. 예전 full/melody 결과도 당시 저장되지 않았다면 소급해서 악보를 복원할 수 없습니다. 같은 설정으로 재생성하면 새 계획이 나올 수 있습니다. 직접 입력한 ABC를 쓴 곡의 replay는 저장된 ABC를 그대로 다시 사용합니다.

## 저장/API/호환성

- 선택적 `input.abc`에 실제 입력 악보를 보존합니다. Song 구조 및 기존 metadata schema 1/2는 유지합니다.
- 입력 악보는 결과 폴더의 `input.abc`에 기록하고 절대 경로를 인자 배열의 `abc_file`로 전달합니다. 사용자 지정 서버 경로는 API로 받지 않습니다.
- full/melody 모드는 기존 `--out`과 함께 결과 폴더를 `--out-dir`로 전달합니다. 생성 악보는 `score.abc`, metadata의 `score`는 출처와 상대 경로입니다. cot=off 명령은 기존 동작을 유지합니다.
- `GET /api/score?id=<run-id>` → `{abc, source}`. `download=1`은 첨부 파일 응답. 외부 경로로 향하는 악보 심볼릭 링크는 거부합니다.
- `POST /api/score/inspect` → `{abc}`의 제한적 헤더 검사. 24,000자/제어문자/K 헤더/본문 유무를 확인합니다. 지원하지 않는 표기와 음악적 오류를 동일시하지 않습니다.
- `POST /api/jobs`는 원문/Section 양쪽 입력에 선택적인 `abc`를 받습니다. 악보 관련 요청 본문은 최대 128KB입니다.
- `version.kind=score_revision`, 버전 비교의 입력 ABC 및 보관 악보 차이를 추가합니다. 기존 버전 관계·휴지통·재생성 동작을 유지합니다.
- 브라우저 초안의 `score_editor`에 사용 여부와 편집 중 텍스트를 함께 저장합니다.
- CLI: `generate --abc-file <file> --cot melody` 또는 `--cot full`. dry-run은 예상 인자만 출력하며 파일을 생성하지 않습니다.
