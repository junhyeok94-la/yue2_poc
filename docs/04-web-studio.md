# Phase 2 — 로컬 웹 스튜디오

2026-09-23 구현 및 실제 GPU 생성 검증 완료.

## 실행

프로젝트 루트에서 `.\web-studio.ps1`을 실행하고 http://127.0.0.1:7860 을 연다.
Python을 직접 지정하려면 `python web_studio.py` 또는 `MUSIC_STUDIO_PYTHON` 환경변수를 사용한다.
서버는 로컬 루프백에만 연결된다. 외부 공개용 서버가 아니다.

스타일 프리셋, 가사 입력, 시드·추론 설정, 작업 로그와 경과 시간, 라이브러리 검색·필터,
재생, WAV 다운로드, 설정 가져오기와 같은 설정으로 재생성을 제공한다.
입력 초안은 브라우저에, 결과 및 메타데이터는 기존 outputs 폴더에 저장한다.
기존 CLI 결과도 라이브러리에 표시된다. 재생성은 새 폴더를 만들고 원본 ID를 기록한다.

## 실행 수명과 제약

서버가 실행 중이면 브라우저를 닫거나 새로고침해도 생성이 계속된다.
동시 생성 요청은 대기열에 넣지 않고 거절하며 CLI와 파일 잠금을 공유한다.
진행률 퍼센트 대신 엔진 로그에서 확인한 단계와 실제 경과 시간을 표시한다.
정상 Ctrl+C 종료 시 실행 중인 생성 스레드가 끝날 때까지 프로세스가 기다린다.
강제 종료는 작업을 중단시킬 수 있다. 남은 잠금은 README의 PID 확인 절차를 따른다.
서버 재시작 후 결과 라이브러리는 복원되지만 메모리의 실시간 작업 패널은 복원되지 않는다.

## 구현과 디자인

Figma: https://www.figma.com/design/gKvtbRwlaaDLsVJRsuWKPe?node-id=3-9

다크 배경, 연두색 주요 버튼, 좌측 작곡 입력·우측 라이브러리와 하단 플레이어를 설계했다.
Figma에서 화면 작성과 스크린샷 확인까지 완료했다. 이후 Starter MCP 호출 한도로
get_design_context와 최종 동기화 검증은 수행하지 못했다. 작성한 디자인을 바탕으로
웹에 작업 상태, 상세 설정 및 모바일 배치를 추가했다.

당초 Gradio 계획은 별도 Python 패키지 없이 Figma 레이아웃을 구현할 수 있는
표준 라이브러리 HTTP 서버와 정적 HTML/CSS/JavaScript로 변경했다.
서체는 IBM Plex Sans KR이며 ui/FONT-LICENSE.txt에 OFL 라이선스를 보존했다.
