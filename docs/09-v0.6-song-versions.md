# v0.6 Song Versions

## 사용법

브라우저를 새로고침한 뒤 라이브러리에서 곡을 선택합니다. Song Versions에서 Variation(설정 변형), Lyrics Revision(가사 수정), Remix(장르/편곡 변경)를 선택하고 “이 곡에서 새 버전”을 누릅니다. 현재 초안을 바꾸는 확인을 거쳐 원본 가사·설정을 가져옵니다.

Compose 상단에 어떤 곡에서 시작했는지 표시됩니다. 필요한 내용을 편집하고 음악 만들기를 누르면 별도 생성 결과로 저장합니다. 시드·스타일·가사는 자동 변경하지 않습니다. Remix도 기존 음원을 편집하는 기능이 아니라 새 설정으로 다시 생성하는 기능입니다.

“독립 곡으로 전환”은 현재 편집 내용을 유지하면서 원본 연결만 해제합니다. 기존 “가사·설정 가져오기”도 독립 곡 초안으로 동작합니다. 버전 초안과 부모 연결은 브라우저에 함께 저장됩니다. 부모가 휴지통에 있으면 생성 요청이 거부되므로 복원하거나 독립 곡으로 전환하세요.

라이브러리는 같은 뿌리를 가진 결과를 묶어 표시합니다. 검색/상태 필터에 표시된 버전 수를 그룹 제목에 표시합니다. Song Versions 목록에는 휴지통에 있는 관련 버전도 표시하여 관계를 잃지 않도록 했습니다. 휴지통 음원은 재생할 수 없습니다.

선택 버전의 부모를 표시하고, 비교 기준 버전을 고른 뒤 “변경 내용 비교”로 제목·가사·최종 스타일·시드·생성 옵션·곡 구조·음악 설정·엔진 설정 차이를 확인합니다. 가사와 구조는 항목별 이전/이후 전체 값을 표시합니다. “기준 듣기”와 “선택 버전 듣기”는 하단 단일 플레이어를 사용하며 매번 처음부터 재생합니다. 자동 박자 정렬·동시 재생 기능은 아닙니다.

## 기록과 호환성

기존 metadata/schema/생성 코어의 계약은 그대로 유지합니다. 새 Web 버전·Replay 결과 폴더에 `version.json`을 추가합니다:

```json
{"parent_id":"2026-09-23/123456-abcdef12", "kind":"lyrics_revision"}
```

원본은 수정하지 않습니다. 생성 시작 콜백에서 관계를 저장하므로 이후 엔진 실패 결과도 관계를 유지합니다. 기존 `metadata.parent_id`도 기존처럼 기록합니다. Web replay는 입력과 당시 엔진 설정을 그대로 사용하고, 수정 버전은 현재 스튜디오 엔진 설정을 사용합니다.

과거 replay는 짧은 `metadata.parent_id`를 라이브러리에서 유일하게 일치하는 ID에 연결합니다. 날짜가 다른 중복 ID는 임의로 연결하지 않습니다. 과거 독립 생성이나 “가사·설정 가져오기” 결과에는 추측으로 부모를 붙이지 않습니다. 삭제된 부모는 휴지통 기록을 통해 관계를 유지하며, 파일이 실제로 없거나 순환 관계가 있으면 경고와 안정적인 그룹 ID를 표시합니다. 기존 파일을 마이그레이션하지 않습니다.

`/api/state`의 각 track에 `parent_id`, `song_id`(관계에서 계산한 그룹 ID), `version_kind`, `lineage_issue`를 추가합니다. 별도 DB와 mutable song 레코드는 도입하지 않습니다.

`POST /api/jobs`는 선택적인 `version: {parent_id, kind}`를 받습니다. kind는 variation/lyrics_revision/remix만 허용하며, 서버가 실제 부모 파일과 상태를 검사합니다. 원본이 실행 중이거나 휴지통 상태이면 생성하지 않습니다. 기존 입력과 Song 입력 모두 지원합니다.

`GET /api/versions/compare?left=<run-id>&right=<run-id>`는 저장된 생성 입력의 변경 항목을 반환합니다. 경로 검증 및 기존 localhost 접근 제한을 유지합니다. UI에서는 같은 가족의 버전을 비교 대상으로 제공합니다.

## 검증 — 2026-09-24

- Python 59개 통과: 기존 테스트와 legacy 관계 해석, 누락/중복/순환 부모, 입력/엔진 비교, 수정 버전·Replay 저장, 서버 재시작 후 관계, 실패 결과 관계, 부모 삭제/복원, 잘못된 요청/실행 중 부모 차단.
- Node/DOM 14개 통과: 기존 모든 UI 테스트와 그룹 표시, 초안 덮어쓰기 취소, Remix 초안 저장·복원·독립 전환, 생성 요청의 부모 ID, 비교 표시, 번갈아 재생 및 원본 입력 보존.
- 실제 사용자 곡을 새로 생성하거나 변경하지 않았습니다. 테스트 대체 생성기로 저장/실패 경로를 검증했습니다.
- 실행 중인 서버에 반영했습니다. 실제 데스크톱 화면 검수는 브라우저 연결 도구 오류로 미완료이며 DOM 테스트로 동작을 확인했습니다. 모바일 검수는 범위에서 제외합니다.
