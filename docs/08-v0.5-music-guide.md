# v0.5 Music Guide

## 사용법

1. 브라우저를 새로고침하고 Compose의 Music Guide에서 음악 설정을 입력합니다. 모든 항목은 선택 사항입니다.
2. 각 항목 아래 “왜? · 설정 가이드”를 열어 설명을 확인합니다. 입력 후보를 선택하거나 직접 작성할 수 있습니다.
3. 추가 스타일에 언어·세부 편곡 등을 자유롭게 작성합니다. 기존 초안의 스타일도 이곳에 보존됩니다. 선택한 설정과 서로 충돌하는 내용은 직접 정리하세요.
4. “YuE2 스타일 미리보기”에서 최종 전달 문구를 확인합니다.
5. “AI 음악 조언”은 현재 음악 설정과 곡 제목만 Gemini에 전송합니다. 가사나 음원은 이 요청에 포함되지 않습니다. 원래 값·제안·이유를 보고 적용/무시를 선택합니다.
6. 음악 만들기를 누르면 기존 YuE2 생성 경로로 전달합니다.

BPM/Key는 생성 의도를 전달하며 출력 템포나 조성의 정확한 준수를 보장하지 않습니다. 모델 출력 음원 분석이나 오디오 편집은 포함하지 않습니다.

AI는 한 요청에 최대 3개 서로 다른 필드의 제안을 반환합니다. 자동 덮어쓰기·자동 재시도는 없습니다. 직접 입력하거나 곡 제목/자유 스타일을 변경하면 이전 제안은 적용할 수 없습니다. 한 제안을 적용해도 같은 요청의 나머지 제안은 계속 적용할 수 있습니다. 기존 가사 AI와 서버 요청 잠금을 공유합니다.

## 데이터와 호환성

`music_settings`는 `advanced_prompt`와 선택적인 `genre`, `bpm`, `key`, `moods`, `vocal`, `instruments`를 담습니다. BPM은 30~300 정수, Key는 `A minor`/`C major` 형식, 분위기와 악기는 문자열 배열(최대 12개), 보컬은 음색/창법 자유 문장입니다. 합쳐진 스타일은 2,000자 이하여야 합니다.

Section 편집의 설정은 기존 schema 2 `input.song.music_settings`에 저장합니다. 원문 편집은 schema 1에 선택적인 `input.music_settings`를 추가합니다. 모든 경우 `input.style`은 실제 엔진에 전달한 최종 문자열입니다. 기존 `advanced_prompt`만 있는 Song, 기존 평면 metadata, CLI 인자는 그대로 호환됩니다. 기존 파일을 일괄 변경하지 않습니다.

컴파일 순서는 Genre → BPM → Key → Mood → Vocal → Instruments → 추가 스타일입니다. 기존 자유 입력만 있을 때는 원문을 그대로 반환합니다. 저장된 설정과 최종 스타일의 일치 여부를 검증하며 replay는 저장된 입력을 사용합니다. 컴파일 규칙 변경 시 이 호환성을 유지해야 합니다.

브라우저 초안 키는 기존 `music-studio-draft-v3`를 유지하며 설정을 추가 저장합니다. 가져오기는 최종 스타일을 다시 추가하는 대신 원래 `advanced_prompt`를 복원하여 중복을 방지합니다.

## API

- `GET /api/music/guide`: 필드별 설명과 입력 후보
- `POST /api/music/preview`: `{music_settings}` 검증 및 최종 `{music_settings, style}`
- `POST /api/music/advice`: `{title, music_settings}` → `{model, suggestions}`. 제안은 `id, field, original, suggested, reason`.
- `POST /api/jobs`: 기존 `song` 입력 지원 확장. 원문 입력은 `style` 대신 `music_settings`를 보낼 수 있습니다. 두 입력의 동시 전송은 거부합니다.

기존 localhost/Origin/요청 헤더/본문 크기 제한을 유지합니다. Gemini 키는 서버에서만 사용하며 기존 환경 설정을 재사용합니다.

## 검증 — 2026-09-24

- Python 53개 통과: 기존 생성/라이브러리/가사 테스트, 설정 검증, 컴파일, 기존 metadata, 원문 생성 전달, Section replay, API 접근 제한, 잘못된 AI 응답과 공유 잠금.
- Node/DOM 13개 통과: 기존 편집/가사 AI/곡 관리, 음악 설정 미리보기·초안 복원·양쪽 편집 모드 요청, 다중 제안 순차 적용·무시·오래된 응답 차단.
- 실제 Gemini API 1회 연결 검증: gemini-2.5-flash에서 BPM/Key/Instruments 제안 3건 수신. 테스트용 제목·설정을 사용했고 사용자 음원은 변경하지 않았습니다.
- 브라우저 연결 도구는 Windows sandbox 초기화 오류로 실행되지 않아 실제 데스크톱 렌더링 검수는 미완료입니다. DOM 동작과 로컬 서버 응답은 검증했습니다. 모바일 검수는 요청 범위에서 제외합니다.
- 이번 변경으로 실제 GPU 곡을 새로 생성하지 않았습니다. 기존 생성 코어는 유지하고 테스트 대체 생성기로 전달 내용과 replay를 확인했습니다.
